**Everyday Wonder, Two Days to Find the Line**

## The entry

One sentence, at most 200 characters, that makes a small everyday moment
strange and new:

> Overnight a spider spun its web across my bicycle spokes, turning my
> morning commute into a trespass through someone else's front door.

## How it works

`main.py` (Python 3.13, standard library only, no network, no randomness)
writes that single sentence to `/output/entry.txt`. The text is fixed, so
every run produces byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```

## Verification

The program was run twice locally; both runs produced byte-identical
`entry.txt` files (see `run1/entry.txt` and `run2/entry.txt`).
